# hs-pediatric-prevalence-meta-analysis
# Random-effects meta-analysis of prevalence: depression and anxiety in
# pediatric patients with hidradenitis suppurativa
#
# Method:   logit-transformed proportions, inverse-variance weighting,
#           REML estimation of tau^2 (package: meta)
# Analyses: for each outcome, a main pooled analysis followed by sensitivity
#           analyses in which selected studies are excluded one at a time
# Data:     Table S2A (anxiety) and Table S2B (depression)
